# Special Design

A responsive creative agency website built from scratch using **HTML5, CSS3, and JavaScript**.

The project focuses on building an interactive and customizable landing page with responsive layouts, theme settings, image galleries, navigation, and local storage persistence.

## 🚀 Live Demo

[View Live Demo](https://ahmed-khalaf1223.github.io/special-design/)


## ✨ Features

* Fully responsive design
* Customizable color themes
* Random background images
* Interactive image gallery
* Smooth section navigation
* Skills progress animation
* Responsive mobile menu
* Navigation bullets
* Settings saved with Local Storage
* Reset settings option

## ⚙️ Main Functionality

### 🎨 Customizable Theme

Users can choose between multiple colors. The selected color is stored in **Local Storage**, so the preference remains after refreshing the page.

### 🖼️ Random Background

The landing page can automatically change its background image every few seconds.

Users can enable or disable this option from the settings panel.

### 🖼️ Image Gallery

Clicking on any gallery image opens it inside a popup with:

* Image preview
* Image title
* Close button
* Overlay background

### 📊 Skills Animation

The skills progress bars animate when the user reaches the skills section while scrolling.

### 🧭 Navigation

The project includes:

* Header navigation
* Navigation bullets
* Smooth scrolling
* Responsive mobile menu

### 💾 Local Storage

The project uses Local Storage to save:

* Selected theme color
* Random background setting
* Navigation bullets setting

## 📱 Responsive Design

The website is designed to work across different screen sizes:

* Desktop
* Tablet
* Mobile

The layout adapts using CSS media queries.

## ▶️ How to Run

Because this project uses JavaScript files and local assets, it is recommended to run it using **Live Server**.

### 1. Clone the repository

```bash
git clone https://github.com/Ahmed-Khalaf1223/special-design.git
```

### 2. Open the project

```bash
cd special-design
```

### 3. Run with Live Server

Open `index.html` using the **Live Server** extension in VS Code.
